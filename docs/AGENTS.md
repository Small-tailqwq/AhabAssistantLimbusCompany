# 文档维护

本目录遵循根 [AGENTS.md](../AGENTS.md)，只保存 AAALC 当前版本的使用、构建、架构、接口与验证方法。

## 内容归属

- `README.md` 导航到已有主题；优先更新对应文档。只有独立、长期维护的主题才新增文件，并补上入口。
- 用户操作、支持范围和实现契约写在对应文档，引用生产源码、配置或测试。依赖版本以项目文件为准。
- 尚未实现的实质方案和长期决策理由放在 [.agents/notes/](../.agents/notes/README.md)，按 [agent-notes](../.agents/skills/agent-notes/SKILL.md) 管理状态和取代关系。相同事实只维护一处，其余位置链接过去。
- 运行报告、逐帧诊断、机器环境、耗时对比和会话记录放在已有的本地证据目录。正式文档保留可复用的方法、证据格式与适用边界；测量结论须有可定位的来源和条件。

## 更新与删除

- 文档描述当前行为。功能、路径、参数或默认值变化时，同次更新对应说明。
- 失效命令、旧实现设计稿和重复说明直接删除，并修复入链；不在 `docs/` 建历史副本或日期式工作日志。
- 新提案使用 `.agents/notes/proposed/`，不重建 `docs/superpowers/` 或其他平行决策目录。
- 区分源码契约、合成场景、截图回放和实机运行。说明每种验证实际覆盖什么，运行结果保留在对应报告中。
- 已封存 notes 遵循其冻结契约，文档清理不修改归档正文或出链。

## 验证

纯文档编辑检查内容、文件链接、标题锚点和 diff。修改本文件或根指引时运行 `python scripts/check_agent_guidance.py`；修改 notes 时运行 `python scripts/agent_notes.py check`，写笔记正文后再运行 `python scripts/agent_notes.py lint <笔记相对 notes 的路径>` 并判定每条命中。
