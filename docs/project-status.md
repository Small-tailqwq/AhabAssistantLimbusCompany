## 定位

金丝雀小助手是 AALC 的非官方 fork，定位为 **100% vibe coding 实验项目**，主要用于实验与测试，仅不定期维护，不保证问题得到及时修复。人负责需求、取舍和结果判断，AI 参与实现、重构与排障。

发布以 Canary Pre-release 为主。自动化依赖实际游戏画面，游戏更新、队伍差异、输入方式和显示环境都可能造成失败或误操作；用户应充分了解并自行承担使用风险，包括游戏账号相关风险。如果只是希望使用 AALC 完成日常，建议下载 [AALC 原项目官方稳定版](https://github.com/KIYI671/AhabAssistantLimbusCompany/releases/latest)。

## 当前实现

版本文件为 **v1.5.0-canary.24**。下表描述当前源码入口；源码变更与发行包内容需分别核对。

| 范围 | 已有实现 | 边界 |
| --- | --- | --- |
| 日常 | 启动游戏、经验本、纽本、换体、模块合成与奖励领取 | 依赖关卡解锁、队伍能力、资源及画面识别 |
| 镜牢 | 普通/困难流程、队伍轮换、路线、事件和商店策略 | 不保证所有队伍、事件或突发状态成功 |
| 主题包 | 图形权重界面、队伍独立权重、未知包回退、复刻关键词整理 | 未识别时使用回退权重；权重不等同于禁入规则 |
| PC 输入 | 前台与后台方式 | 权限、焦点及截图方式会影响结果 |
| 模拟器 | MuMu 专用接入与其他模拟器的 ADB 路径 | 各版本和实例配置需单独验证 |
| 桌面分身 | Windows Child Session、任务控制、日志同步、静音与输入开关 | 默认关闭；需要管理员权限和兼容的远程桌面环境；不与模拟器模式并用 |
| 其他实验功能 | OBS 截图、罗技/雷蛇输入、模拟器加速器启动 | 外部组件需要独立配置，不属于基础运行前提 |

## 验证边界

单元测试和冷检查覆盖参数、状态、协议及部分模拟流程；真实任务仍受游戏画面、设备和队伍影响。发布包与源码开发入口的权限不同，桌面分身、驱动输入、困难镜牢和不同分辨率需要分别验证。

具体版本变化见 [更新日志](../CHANGELOG.md)，本次使用反馈需附版本、运行方式、日志与画面。

## 更新与联网

Canary 版本或 Canary 通道从本 fork 获取预发布；普通 Stable 路径使用上游稳定发布并过滤 Pre-release。若要继续使用本项目，请使用本仓库发行包和 Canary 通道。

截图与 OCR 在本机处理。程序还有更新检查与下载、公告，以及按需使用的汉化下载等联网功能，因此不应描述为“除更新外完全离线”。
