# 通行证领取

入口为 [PassRewardFlow](../src/AALC.Runtime/Daily/PassRewardFlow.cs)。[DailyRunner](../src/AALC.Runtime/Daily/DailyRunner.cs) 在邮件后调用它，随后接手续行兑换或返回主页。任务流程复用 `IGameSession` 的截图、输入、网络等待和取消，不建立新的输入后端。

## 选项与顺序

| 选项 | 默认值 | 行为 |
| --- | --- | --- |
| `ClaimRewards` | 关闭 | 奖励领取总开关 |
| `ClaimMissions` | 开启 | 每日、每周任务 |
| `ClaimSeasonMissions` | 关闭 | 赛季任务，包括滚动列表中的可领取项 |
| `ClaimPassLevels` | 关闭 | 全部领取可用的等级奖励 |

选项保存在 AAALC 的 `DesktopSettings.Daily`。旧配置缺少 `ClaimSeasonMissions` 时仍为关闭。执行顺序为每日、每周、赛季、等级奖励；任务带来的升级可以在同次运行领取等级奖励。关闭赛季选项时，即使赛季标签仍有红色提示也不进入该分区。

## 当前识别与动作

所有坐标按截图高度相对 1440 基准缩放，模板经 AAALC 的 `TemplateMatcher` 解析资源、缩放和 bbox 裁剪。进入通行证时，赛季模板未命中便在完整横幅区域 OCR，不先等待多轮失败；入口动作间隔至少一秒，总共最多 16 次观察。

任务页同时要求任务标签模板、每周标签模板和高亮边框成立。标签边框的金色像素比例至少 0.25，且高于其他同级标签的 1.6 倍；切换期间两侧边框同时发亮时继续等待。等级页还要求每周标签消失。点击标签后每 150 ms 重新观察，最多 12 次。

分区红色提示使用标签右上小区域的像素比例：`R>100`、`R>1.7G`、`R>1.7B`，比例大于 0.3。只在确认页面后读取这个标记；无提示时跳过该分区，省去点击与 OCR。

有提示时，在 `(1180,350,1420,1240)` 识别任务进度，只接受上边界至少为 380、下边界不超过 1240 的文字框。满进度和橙色判定规则为：文字框向左／上／右／下扩展 `150/18/25/18` 基准像素；OpenCV HSV 范围 `5<H<35`、`S>80`、`V>60`，比例至少 0.12。

每次只点击当前帧的一行，150 ms 后重新观察。原点击区域仍保持可领取橙色时等待，不重复点击；最多等待 12 次。网络连接和重试提示仍由 `GameSession.ObserveAsync` 处理。分区提示消失时立即返回，不再 OCR、滚动或寻找列表末尾。每日／每周仍有提示但连续四次未找到可领取行时返回失败。

赛季只在提示仍在且当前没有可领取行时滚动：使用现有 `DragAsync`，在任务列表内上下拖动 520 基准像素，保留相邻视口重叠。先从当前位置向下扫描，列表内容没有变化时改为向上；反方向也不变且提示仍在时报告未完成。整个分区最多 60 次循环，所有等待与拖动接受取消。内容比较限定在任务文字和进度条区域，避开底板边缘动画。

等级页有提示时，OCR 必须识别“全部领取”“领取全部”或 `Claim All`，才点击文字中心。点击后在三十秒内每 200 ms 观察一次，优先处理“获得奖励”弹窗，确认一次后等待关闭，再要求仍位于等级页且提示消失才报告完成。若没有观察到弹窗，点击后至少等待三秒，再以等级页提示消失作为完成条件。弹窗未关闭或提示持续存在则失败，不重复点击领取或确认。

等级奖励中的新 E.G.O. 会先进入全屏展示。仅在已提交等级领取、通行证标签不可见，且右下区域同时识别到 `SEASON` 编号与 E.G.O. 危害等级时点击推进，再等待普通奖励确认框。展示推进至少间隔两秒；未知画面保留并失败退出。

奖励确认复用 `mail/get_mail_prize_confirm.png`，仅在点击等级领取后的观察中查询。弹窗出现时背景提示可能已经消失，因此确认模板先于完成判断。
