# 配置指南

[首页](../../../README.md) · [使用指南](How_to_use.md) · [English](../en/Custom_setting_EN.md)

## 日常与领奖

任务勾选和任务参数分开设置。检查经验本/纽本次数、日常队伍、按日期指定队伍、狂气换体次数，以及任务完成后的动作。领奖可以分别选择邮件、日常/周常和通行证等级奖励；不要把未勾选的领奖项当成运行失败。

## 镜牢队伍

在队伍界面启用需要的队伍并排列执行顺序，核对游戏内队伍序号或名称识别方式。每支队伍可设置体系、罪人顺序、商店策略和主题包权重等。

困难镜牢、周常加成、提前退出、保留奖励和无限次数会改变实际流程。首次配置先使用有限次数，确认队伍及奖励行为符合预期，再扩展运行范围。

## 主题包权重

优先使用图形界面修改权重。数值越大，候选优先级越高；选择还受刷新阈值、刷新次数及其他策略影响，低权重不保证永不进入。

- 全局权重与队伍独立权重分开保存；启用独立权重后检查对应队伍配置。
- “未知”控制未识别主题包的回退权重。
- C24 整理了中英文关键词、零协会新译名、复刻共用权重和轨道线条目。
- 配置同步只保留默认名单仍存在的关键词。自行添加的旧关键词可能在同步时被移除，升级后应检查自定义权重。

<details>
<summary>配置文件位置</summary>

| 文件 | 用途 |
| --- | --- |
| `config.yaml` | 主配置、任务与队伍设置 |
| `theme_pack_list.yaml` | 全局主题包名单与权重 |
| `theme_pack_weight/theme_pack_weight_team_<编号>.yaml` | 队伍独立主题包权重 |
| `assets/config/config.example.yaml` | 随程序分发的默认配置示例 |

修改前停止任务并备份。不要用示例文件覆盖用户配置，也不要把含凭据的配置提交到仓库。桌面分身有单独的配置与日志范围，不要假定分身和主控正在读写同一文件。

</details>

## 输入、截图与实验功能

PC 可选择前台或后台输入。罗技/雷蛇输入需要额外 DLL 与环境配置；OBS 截图需要可连接的 WebSocket 服务和正确的游戏捕获源。它们不是普通运行的必选项。

桌面分身默认关闭，先做兼容性检查，再逐项启用。不要一次同时改变输入通道、截图方式、分辨率和运行速度，否则难以判断问题来源。

调试模式及其子开关用于保存特定流程的证据，截图通常在 `logs/` 下。开启所需项即可；关闭父级调试模式会重置子开关。
