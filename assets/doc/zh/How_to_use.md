# 使用指南

[首页](../../../README.md) · [FAQ](FAQ.md) · [配置](Custom_setting.md) · [English](../en/How_to_use_EN.md)

本指南面向金丝雀小助手实验分支。实际支持范围见 [项目现状](../../../docs/project-status.md)。

## 安装与更新

1. 从[本仓库 Releases](https://github.com/Small-tailqwq/AhabAssistantLimbusCompany/releases) 选择 Pre-release，下载 `AALC_<版本>.7z`。GitHub 自动生成的 Source code 不是 Windows 安装包。
2. 完整解压到可写目录，运行 `AALC.exe`。不要只复制单个 exe；发行包还需要 `_internal/`、`assets/` 和更新器等文件。
3. 发行包的 `AALC.exe` 会请求管理员权限。首次运行后在设置中核对游戏路径、游戏语言与窗口分辨率。
4. 更新前停止任务并备份 `config.yaml`、`theme_pack_list.yaml` 与 `theme_pack_weight/`。使用程序更新或下载新包；手动迁移时不要用示例配置覆盖自己的配置。

Canary 通道及名称含 `-canary` 的版本从本 fork 检查更新。普通 Stable 路径对应上游稳定版，不是本 fork 的稳定性承诺。更新失败时保留日志，再尝试手动下载同一目标版本。

## 第一次运行

1. 先确认游戏能正常登录并进入主界面，目标关卡已经解锁，队伍能完成所选任务。
2. 让 AALC 的游戏语言与实际游戏一致；界面语言是另一项设置。调整分辨率后确认截图完整、比例正确。
3. 在任务页选择日常、领奖、换体或镜牢，核对次数、队伍、狂气消耗及任务结束后的动作。
4. 初次使用保留默认速度，关闭不需要的实验功能，先执行少量任务并观察日志。
5. 若卡住或误点，先暂停或停止，保留当时的游戏画面和日志，再按 [FAQ](FAQ.md) 排查。

## 暂停、恢复与停止

| 操作 | 默认快捷键 |
| --- | --- |
| 请求停止当前任务 | `Ctrl+Q` |
| 暂停或恢复任务 | `Alt+P` / `Alt+R` |

快捷键可在设置中更改。停止走协作式收尾，不等同于杀死程序；等待任务结束、按钮恢复空闲后再启动。快捷键未生效时使用界面按钮，并检查焦点、输入方式和权限。

<details>
<summary>模拟器</summary>

在设置中启用模拟器并选择对应类型，填写实际实例和连接信息。MuMu 有专用接入，其他类型走 ADB 路径；不要照抄旧教程中的固定端口。

- 从模拟器当前实例的诊断或设置页面确认 ADB 端口及调试状态。
- 让模拟器画面分辨率与 AALC 窗口设置一致。
- MuMu 的应用保活可能影响截图；出现黑屏或旧画面时检查该项。
- 连接失败时记录模拟器版本、实例编号、端口与日志，不要同时启动多个任务争用同一实例。

</details>

<details>
<summary>后台输入与桌面分身</summary>

PC 后台输入和桌面分身是两种不同方式。后台输入仍依赖当前会话的游戏窗口与可用截图，不保证最小化、锁屏或远程会话切换后继续正常工作。

桌面分身默认关闭，通过独立 Windows Child Session 运行任务。启用前使用工具箱中的兼容性检查；需要管理员权限和兼容的远程桌面环境，Windows Home 不在当前首发支持范围内，也不能与模拟器模式并用。可在主控控制任务、查看同步日志，在分身窗口切换声音与输入。退出时使用工具提供的停止任务并注销分身入口。

</details>

<details>
<summary>命令行启动已配置的任务</summary>

在程序目录执行：

```powershell
.\AALC.exe start
.\AALC.exe start --exit
```

`start` 使用已保存的任务设置；`--exit` 未带数值时表示任务结束后退出 AALC。它会实际执行所选任务，请提前核对次数和结束动作。其他兼容参数的解析见 `app/my_app.py::command_start`，不要把旧版下拉框索引当作当前界面说明。

</details>
