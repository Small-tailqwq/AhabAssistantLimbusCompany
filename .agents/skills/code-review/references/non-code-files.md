# 审阅生成与非代码文件

不能只因文件是生成的或二进制的就忽略。每个都按承载行为的产物审阅。

| 文件类型 | 需验证内容 |
|---|---|
| Lockfile | 对应有意的依赖 manifest 变更；标记无法解释的变动 |
| 编译翻译 | 核验源翻译与生成器关系，而不是逐行审阅二进制输出 |
| 图片 | 变更依赖它们时检查键、语言/主题位置、尺寸与代码引用 |
| 更新日志与发布元数据 | 属于发布范围时核验准确性 |
| 压缩或打包产物 | 核验源码/生成器溯源与意外包含 |
| CI、构建脚本、示例配置、迁移、更新 manifest | 完整行为审阅 |

生成输出与源不一致时，报告源/生成器的一致性问题，而不是生成文本本身。
