# 动效标准与数值

来源同主技能。审阅 finding 时引用这里的具体值，不要给约数或临时编造的曲线。

## 频率门槛

| 频率 | 决定 |
|---|---|
| 每天上百次（快捷键、Esc、运行/停止、日志滚动） | 不动画 |
| 每天几十次（悬停、侧栏切换、频繁开关） | 只允许几乎察觉不到的透明度或颜色变化 |
| 偶尔（对话框、浮层、通知、保存反馈） | 标准动画 |
| 首次或罕见（关于页、空状态、完成反馈） | 可以多一点，仍不阻塞操作 |

键盘触发的动作是排除项，不是判断题。

## 目的

必须能用一个词说清：反馈、空间连续、状态指示、避免突变、说明、愉悦。愉悦只属于罕见场景。用户正在阅读或操作的数据不因装饰而移动。

## 缓动

| 场景 | Avalonia 12 |
|---|---|
| 进入、退出 | `SplineEasing X1="0.23" Y1="1" X2="0.32" Y2="1"`，或现有 `CubicEaseOut` |
| 屏内移动 | `SplineEasing X1="0.77" Y1="0" X2="0.175" Y2="1"`，或 `CubicEaseInOut` |
| 悬停、颜色 | 现有 `BrushTransition` 的默认缓动 |
| 匀速（进度） | `LinearEasing` |

决策顺序：进出用 ease-out；屏内移动用 ease-in-out；悬停颜色用默认；常量运动用 linear；拿不准用 ease-out。`EaseIn` 不用在入场，它把用户最关注的起始阶段拖慢。

## 时长

| 元素 | 时长 |
|---|---|
| 按下反馈 | 100–160 ms |
| 小浮层、ToolTip | 125–200 ms |
| 下拉、选择 | 150–250 ms |
| 对话框、抽屉 | 200–500 ms |
| 常规 UI | 不超过 300 ms |

项目已定的 220/180/120 ms 优先于本表；新增值从表内取，并与现有值保持接近。

## 物理性

- 入场从 `0.94–0.97` 的缩放加 `Opacity 0` 开始，从 0 开始会像凭空出现。
- 浮层从触发点缩放；居中对话框保持中心。
- 按下反馈 `0.97`、100–160 ms。项目按钮当前用 6%/12% 叠加层表达悬停与按下，保持现状；改按下效果属于改设计规范，先确认。
- 位移用自身尺寸的百分比，不写死像素。

## 可打断

- `Transitions` 在目标值改变时从当前值重定向，适合 Toast、切换、连续点击。
- `Animation` 关键帧会从头重放，只用于低频入场或循环装饰。
- 入场与出场同路径；不绕路。
- 非对称时序：慢在用户决定处，快在系统响应处。
- 关闭不等待动画；输入与焦点不被动画阻塞。

## SpringEasing

Avalonia 12 的 `SpringEasing` 属于时长驱动的缓动，不是物理弹簧。只在交互可被打断、需要轻微惯性时使用，从 `Mass=1, Stiffness=100, Damping=10` 起步；默认临界阻尼、不要回弹，回弹只用于拖拽释放一类有动量的交互。

## 性能

- `RenderTransform` 与 `Opacity` 不触发布局测量与排列；`Width`、`Height`、`Margin`、`Padding` 会触发。
- 不要用父级属性驱动多个子元素逐帧变化；在目标元素上直接改。
- `PointerMoved` 里只做必要的值更新，不查找资源、不改样式、不创建控件。
- 循环动画随控件卸载或不可见停止；项目 AboutView 的 logo 波浪依赖 Avalonia 的可见性管理。
- 阴影、模糊、裁剪下的动画更贵；不是必须就不要叠加。

## 无障碍

- Avalonia 12 的 `IPlatformSettings` 没有动画开关；不要声称已支持系统“减少动效”。要接入 Windows 设置需单独实现并验证。
- 键盘焦点、Esc、快捷键触发的操作不加位移或缩放；焦点环立即可见。
- 减少动效意味着更少、更缓，不是全关：保留帮助理解的透明度与颜色变化，去掉位移与缩放。
- 避免长期低频摆动和突然的亮度跳变。

## 十条审查标准

违反任一条就是 finding：

| 禁止 | 改为 |
|---|---|
| 给整个控件加泛化过渡，包括不需要的属性 | 只列真正要变的属性 |
| `scale(0)` 入场 | `0.94–0.97` 加 `Opacity 0` |
| 入场用 `EaseIn` | `SplineEasing` 的 ease-out 或 `CubicEaseOut` |
| 键盘或每天上百次的操作加动画 | 不动画 |
| 没有理由超过 300 ms | 150–250 ms |
| 浮层从中心缩放 | 从触发点缩放；对话框除外 |
| 快速触发元素用 `Animation` 关键帧 | 用 `Transitions` |
| 动画 `Width`、`Height`、`Margin` | `RenderTransform`、`Opacity` |
| 每个列表都逐项 stagger | 低频列表一次进入；高频列表不加 |
| 动画阻塞输入、延迟焦点返回 | 立即可操作，关闭不等动画 |

## 调试

- 把时长临时放大 2–5 倍，观察颜色是否干净过渡、缓动是否突然停顿、原点是否正确、多个属性是否同步。
- 次日复看；开发时看不出的问题会在隔天显现。
- 在 100%、150%、200% DPI 和最小窗口尺寸下各看一次。
