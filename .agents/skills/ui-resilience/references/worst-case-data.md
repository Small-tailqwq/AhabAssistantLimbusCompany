# 最坏数据目录

取值原则：真实用户可能产生，或后端、文件系统、游戏窗口真实允许的上限。不用重复字符凑长度。

## 文本

| 类型 | 取值示例 | 关注点 |
|---|---|---|
| 中文长名 | “以实玛利·逸乐·四阶·满级满同步” | 换行、截断、行高 |
| 英文长名 | `Bartholomew Fitzgerald-Montgomery` | 无中日韩断行点 |
| 中英混合 | `镜牢 Hard 三层 (Infinite)` | 混排断行 |
| 无空格长串 | `mirror_infinity_floor_3_boss_reward_pack` | 必须能截断或换行 |
| 含标点 | `“燃烧”/“流血”·+3` | 引号、斜杠、间隔号 |
| 其他文字 | 日文、韩文、俄文、阿拉伯文（RTL） | 字体回退、方向 |
| 空字符串 | `""` | 不留孤立分隔符或空行 |

## 路径

| 类型 | 取值示例 | 关注点 |
|---|---|---|
| 深层目录 | `C:\Users\Ko_teiru\Documents\code\AhabAssistantLimbusCompany\artifacts\...` | 单行撑开 |
| 含空格 | `C:\Program Files\...` | 断行位置 |
| 中文路径 | `D:\游戏\边狱公司\截图` | 字体与截断 |
| 超长文件名 | 200 字符文件名 | 单行截断 |
| UNC | `\\server\share\...` | 前缀识别 |

## 数字

- 0、1、2、9、10、999、1,000、1,000,000。
- 计数为 1 时的单复数与量词。
- 极大值导致布局变宽；负值、浮点（费用、概率、权重）、百分比。
- 空值或未加载时的占位，不显示 `NaN`、`-1`、`undefined`。

## 时间

- 刚刚、几秒前、昨天、7 天前、跨年、时区差异。
- 任务开始/结束时间、持续时间超过 24 小时。
- 时间格式统一，不在同一界面混用相对与绝对。

## 集合

- 空列表：0 个窗口、0 个卡包、0 条日志。
- 单条：1 个窗口、1 个卡包、1 条日志。
- 大量：窗口列表 20+、卡包列表 50+、日志 500+ 行、队伍与罪人全选。
- 列表项内容长短不一，第一项就是最长项。

## 状态

- 未选择游戏窗口、加载中、运行中、已停止、失败、部分成功、已取消。
- 任务名与状态文字组合后过长。
- 运行中同时显示停止按钮和错误文本。

## 错误与日志

- 常见异常：文件不存在、权限不足、游戏窗口关闭、OCR 模型缺失、网络失败。
- 长错误消息：多行、含路径、含堆栈或嵌套异常。
- 中文错误与英文异常混合。
- 日志包含超长单行（例如序列化的 JSON 或路径列表）。

## 游戏上下文

- 游戏窗口标题：带版本号、分辨率、`Limbus Company` 前后缀。
- 任务名、罪人名、卡包名、饰品名、主题包名。
- 费用、星光、次数、进度（`3/15`）。
- OCR 结果可能为空、含噪声或多余空格。

## 环境

- 100%/150%/200% 显示缩放。
- 最小窗口尺寸（`MainWindow` 1040×700）。
- 暗色主题；高对比设置。
- 系统语言与字体缺失时的回退。
