# Canary 恢复与回滚

这里每一项都会变更已发布状态。先识别精确的 release、产物或 tag 并取得授权再行动。

| 情况 | 处置 |
|---|---|
| 重复或错误产物 | 未识别出精确 release 与产物且未获授权删除前，不删除 |
| 已发布 tag 指向错误提交 | 停止分发并报告；替换 tag 具有破坏性，需要明确批准 |
| canary 对稳定版用户可见 | 先修 release 元数据或通道过滤再宣布 |
| manifest 不匹配 | 从构建脚本重新生成，创建可追溯的修正发布状态 |
| canary 行为异常 | 在 release body 中记录回滚或上一个已知良好版本，并报告通道影响 |

在最终报告中记录修复或回滚状态。
