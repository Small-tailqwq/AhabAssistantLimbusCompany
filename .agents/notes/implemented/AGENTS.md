# 已实施的 Agent Notes

按[文件格式](../README.md#the-file-format)记录当前实现。代码改变路径、符号、默认值或实现机制时，同次更新笔记中的事实，用现在时描述。

事实更新可就地完成；决策或理由被改变时，写新笔记并互相链接。完全取代的笔记只有满足[合并条件](../README.md#when-to-write-one)才可删除。

不再指导后续工作的记录按 [agent-notes skill](../../skills/agent-notes/SKILL.md) 退役。运行 `uv run python scripts/agent_notes.py check`。
