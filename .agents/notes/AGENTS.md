# Agent Notes 指引

本目录保存影响后续工作的提案、决策理由、真实替代方案、后果和必要验证。遵循根 [AGENTS.md](../../AGENTS.md)、[笔记契约](README.md) 和 [agent-notes skill](../skills/agent-notes/SKILL.md)。

每条新笔记都要搜索活跃目录中同一决策或机制的记录，在同次变更中判断完全取代、部分取代或并存。部分取代的记录保持活跃并互相链接；清理仍遵循根规则的授权与资产边界。

[archived/](archived/AGENTS.md) 是冻结的历史资料，不作为当前行为依据。

修改本目录后运行 `uv run python scripts/agent_notes.py check`。
